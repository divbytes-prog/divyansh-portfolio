# Divyansh Singh — Portfolio

My personal developer portfolio showcasing selected projects, technical work, experiments, and the way I approach building software.

**Live site:** https://divyansh-portfolio-pearl.vercel.app

## Highlights

- Custom asymmetric editorial layout
- Interactive motion and scroll-based transitions
- Live project architecture visualization
- Project cards with pointer-driven interactions
- Generative WebGPU visuals
- Responsive mobile and desktop layouts
- Personal profile and project storytelling
- Reduced-motion support

## Tech stack

- React
- Vite
- Motion for React
- React Icons
- VGPU / AeroShards
- Custom CSS

## Run locally

```bash
git clone https://github.com/divbytes-prog/divyansh-portfolio.git
cd divyansh-portfolio
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deployment

The portfolio is deployed on Vercel and automatically redeploys from the main branch.
